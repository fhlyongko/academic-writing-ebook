# Academic Writing and Research

A Practical Guide for International Students in Korean Universities. Yong-Jik Lee, Ph.D., Changwon National University.

A web edition of the author's 57-page PDF, offered in two reading modes.

| Edition | Path | Character |
|---|---|---|
| Reference | / | Sticky sidebar contents, for looking things up |
| Serial | /read/ | Single column, one episode at a time |

## Contents

Sixteen chapters in three parts, plus references and an about page.

## Reading features

Progress bar, dark mode, checklist persistence, arrow-key paging, print layout, responsive design. No CDN, no web fonts, no trackers, so it works offline.

## Fidelity to the source

No sentence was added, removed, or rewritten. Only PDF line-wrap restoration and removal of running heads and page numbers. An automated check confirmed 100 percent word-level preservation across all sixteen chapters.
